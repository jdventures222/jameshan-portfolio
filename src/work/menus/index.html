The problem

The project began with a restaurant in the group and its designed PDF menu in English. Guests read many languages, and anyone with an allergy had to ask about each dish.

The goal

One system every brand in the group could use:

  • Each dish in {{menus.languages}} languages with its allergens on the page.
  • A printable menu for the table.
  • All of it built from one set of data, so a change is made once.

What I built

  • A phone menu for every brand and location, in {{menus.languages}} languages, one tap to switch.
  • An allergen filter for {{menus.allergens}} allergens that flags or hides every dish containing one.
  • Print-ready PDFs of every menu in every language: {{menus.pdfs}} of them.
  • A QR code for each brand and location, and a directory of every brand’s menu.
  • One Python build that makes the web pages and the PDFs from the same data.

Keeping menus current

Prices are changed once in the menu data; dish text is updated in each language. The build remakes the phone menus and the PDFs in every language.

How ongoing changes work

Decisions

  1. Keep allergen warnings available without JavaScript.

    Each page includes a plain menu for when JavaScript is switched off. Every dish in that menu keeps its allergen warning.

    Why: a guest with an allergy should never see a menu without its warnings, whatever phone or browser they use.

    Trade-off: that fallback is in English only, without the language switch or the photos.

  2. Right to left is the whole layout, not just the text.

    In Arabic, Farsi and Urdu the whole page mirrors and reads from the right, not just the text. In the printed menus, prices and English names inside those lines keep reading left to right.

    Why: a mirrored sentence inside a left-to-right page still reads as a translation stuck onto an English menu.

  3. Each script gets its own print rules.

    The PDFs use typefaces drawn for Korean, Chinese, Japanese, Arabic, Farsi, Hindi and Russian, and traditional Nastaliq for Urdu.

    • Line height follows the script.
    • Scripts without capitals get no forced capitals or letter-spacing.
    • Korean and Japanese keep their own line-break rules.

    Why: a printed menu in the wrong typeface, or with clipped letters, is the first thing a native reader notices.
