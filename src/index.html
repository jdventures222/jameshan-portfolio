Includes: {{menus.languages}} languages, one-tap switching, right-to-left Arabic, Farsi and Urdu · allergen filter · each brand’s own colours and photos · print-ready PDFs in every language · QR codes per brand and location · one Python build pipeline

  • {{menus.languages}} languages, switched with one tap; Arabic, Farsi and Urdu flip the whole layout to read right to left.

Fyt: run club and gym tracker

{{fyt.users_display}} users

Most fitness apps are built for one person. Fyt is built for a group: friends who run and lift together. Members track their runs and gym sessions, and Fyt announces each one live in the club’s iMessage group chat, so the crew can cheer every mile and every PR, including members who don’t have the app.

Includes: iPhone and Apple Watch app · server and database · public website · a live subscription tier

What I built

  • The iPhone and Apple Watch app (Swift): live GPS run recording with pace, distance, elevation and heart rate; a gym logger with sets, reps, weights and a rest timer; workouts imported automatically from Apple Health.
  • The server and database (TypeScript, PostgreSQL): the API plus background jobs that import workouts, find personal records and update leaderboards, hosted on Fly.io.
  • The public website and a live subscription tier through Apple, with a shareable page for every workout.
